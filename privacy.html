What this sitecollects.

Nothing. Here's the longer version.

No analytics, no cookies, no tracking

This site is a static set of HTML, CSS, and JavaScript files. It does not run any analytics service, set any cookies, or load any third-party scripts that could track you across the web. There is no "consent banner" because there is nothing to consent to.

Self-hosted assets

All fonts (Philosopher, Mulish, JetBrains Mono), images, and icons are served from the same origin as the site itself. Your browser does not contact any other domain when you view these pages.

Outbound links

The Publications and Contact pages link to external services (Google Scholar, LinkedIn, journal DOIs, individual paper hosts). When you click those links you are leaving this site, and the destination's privacy policy applies. This site does not transmit any information about you to those destinations beyond the standard HTTP referrer that any web browser would send.

What GitHub Pages logs

This site is hosted on GitHub Pages, which logs request metadata (IP address, user agent, requested path, timestamp) for purposes of delivery, abuse prevention, and aggregate analytics. I do not have access to those logs. GitHub's handling of that data is governed by their general privacy statement.

Email

If you email me at robinzjephthah@gmail.com, I receive the message in my Gmail inbox. I do not add you to any mailing list. I do not share your email with anyone.

Changes
