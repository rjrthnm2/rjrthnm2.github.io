# Contributing

This is a personal site, so it's not really set up for outside contributions
in the way an open-source project is. That said, if you spot a typo, broken
link, or accessibility issue, please open an issue or pull request — those
are always welcome.

## Filing an issue

Use the templates under `.github/ISSUE_TEMPLATE/` (bug report or feature
request). A short, specific report — what page, what browser, what you saw
versus what you expected — is plenty.

## Submitting a pull request

1. Fork the repo and create a branch off `master`.
2. Make the change. There's no build step, so just edit the HTML / CSS / JS
   directly and preview with `python -m http.server` (see `README.md`).
3. Open a pull request describing what changed and why.

For anything beyond a small fix, please open an issue first so we can talk
through scope before you put time into a PR.
